# Hackathon Submission Checklist

This project is built for the IBM Bob Hackathon 2026. Before submission, verify:

- [ ] The solution clearly demonstrates IBM Bob IDE as part of the build workflow.
- [ ] A Bob IDE task session report has been exported and committed under `bob_sessions/`.
- [ ] The repository does not expose IBM Cloud API keys, watsonx credentials, or other secrets.
- [ ] Public data sources, if any, are documented in `DATA_SOURCES.md`.
- [ ] The README explains how the project still works without optional IBM Cloud credentials.
- [ ] Demo steps are reproducible from a fresh clone.

## Bob report requirement

The official guide states that participants must export and upload a Bob IDE task session report in the code repository for judging. Place the exported report file in `bob_sessions/` before final submission.
