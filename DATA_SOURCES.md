# Data Sources

ShipSage does not rely on a bundled external dataset. It analyzes public GitHub repositories supplied by the user at runtime.

If the project is extended with additional public datasets or scraped sources, list each source here with:

1. Source name
2. URL
3. What data was used
4. License / terms permitting use
5. Date accessed

Do not include personal information, client data, social-media-derived personal data, or confidential material.
